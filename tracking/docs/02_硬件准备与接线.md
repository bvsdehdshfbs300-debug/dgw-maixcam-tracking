# 硬件准备与接线

这一页先讲硬件怎么接。第一次复刻时，不要急着开自动追踪，先保证每一部分单独能工作。

## 硬件清单

- MaixCAM Pro。
- ESP32-S3 开发板。
- X 轴闭环步进电机。
- Y 轴闭环步进电机。
- 电机外部供电模块。
- USB 数据线两根，一根接 MaixCAM，一根接 ESP32-S3。
- 杜邦线若干。
- 二维云台机械结构。

## 整体连接关系

```text
MaixCAM Pro
  └─ WiFi/手机热点
       ↓ UDP
电脑
  └─ USB 串口
       ↓ M x y / P us
ESP32-S3
  ├─ X_STEP / X_DIR
  └─ Y_STEP / Y_DIR
       ↓
两个闭环步进电机
```

## ESP32-S3 到电机的推荐接线

如果你使用的是之前这套 ESP32-S3 固件，默认接线如下：

| ESP32-S3 引脚 | 连接到 | 作用 |
|---|---|---|
| GPIO7 | X 轴电机 Stp / Pul / STEP | X 轴脉冲 |
| GPIO15 | X 轴电机 Dir / DIR | X 轴方向 |
| GPIO4 | Y 轴电机 Stp / Pul / STEP | Y 轴脉冲 |
| GPIO5 | Y 轴电机 Dir / DIR | Y 轴方向 |
| GPIO6 | 激光灯控制脚，可选 | 开关激光 |
| GND | 电机信号 GND / 电源负极参考地 | 共地 |

不同电机端子名字可能略有差异：

- `Stp`、`Pul`、`STEP` 通常都是脉冲输入。
- `Dir`、`DIR` 通常都是方向输入。
- `Gnd` 是信号地。
- `V+`、`V-` 是电机动力电源，不要接到 ESP32 的 5V/3.3V。

## 电机供电

电机必须使用外部电源。不要用 ESP32-S3 的 USB 口给电机供电。

基本原则：

- 电机 `V+` 接外部电源正极。
- 电机 `V-` 接外部电源负极。
- ESP32-S3 的 `GND` 要和电机信号 `GND` 共地。

共地很重要。ESP32 输出的是 3.3V 逻辑信号，如果没有共同参考地，电机可能看不懂 STEP/DIR 的高低电平。

## EN 口要不要接

本项目的 STEP/DIR 控制一般不需要先接 `EN` 口。

原因是：

- `STEP` 才是“走一步”的脉冲输入。
- `DIR` 才是“往哪个方向走”的方向输入。
- `EN` 多数情况下是使能/脱机控制，不是用来控制每一步运动的主脉冲口。

如果你的电机参数里启用了外部 EN 控制，EN 没接可能导致电机不响应。新手建议先在电机菜单或上位机里确认：

- 电机处于使能状态。
- 脉冲控制模式可用。
- STEP/DIR 逻辑电平和细分设置正确。

## MaixCAM Pro 接线

MaixCAM Pro 这一版方案不直接接电机，只需要：

- USB 连接电脑，用 MaixVision 运行代码。
- 连接到和电脑相同的 WiFi 或手机热点。

MaixCAM Pro 负责识别目标和发送坐标，不负责输出电机脉冲。

## 第一次上电顺序

推荐顺序：

1. 只接 ESP32-S3 USB，不接电机电源。
2. 用串口测试 ESP32 是否能收到命令。
3. 接电机信号线，但电机先不要装到云台结构上。
4. 打开电机电源，发送很小的移动命令。
5. 确认 X/Y 方向正确。
6. 再安装云台结构。
7. 最后启用视觉自动追踪。

## 安全检查表

第一次让电机动之前检查这些：

- 电机电源电压符合电机要求。
- 电机电源电流能力足够。
- ESP32-S3 GND 和电机信号 GND 已共地。
- STEP 和 DIR 没接反。
- X 轴和 Y 轴没接反。
- GUI 仍处于 `dry-run`，还没有真正发送运动命令。
- 云台周围没有手指、线材、工具卡住结构。
