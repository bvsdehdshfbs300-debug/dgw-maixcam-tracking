# PC 端 GUI 使用

PC 端 GUI 是整个项目的调试中心。它接收 MaixCAM 发来的坐标，显示目标位置，计算电机命令，并通过串口控制 ESP32-S3。

## 运行环境

电脑需要 Python 3。

安装串口库：

```powershell
pip install pyserial
```

Tkinter 是 Python 常见自带库，一般不需要单独安装。

## 启动 GUI

在 PowerShell 中运行：

```powershell
python ".\pc端GUI\GUI.py"
```

如果你的项目路径不同，把命令里的路径改成自己的。

## GUI 的核心功能

GUI 主要有这些功能：

- 启动/停止 UDP 监听。
- 显示 MaixCAM 发来的 `dx/dy/score`。
- 在画布上显示目标相对中心的位置。
- 调整 PID 参数。
- 调整最大步数、死区、平滑系数等安全参数。
- 连接 ESP32-S3 串口。
- 开启或关闭自动锁定。
- `dry-run` 只模拟不真实发电机命令。

## 第一次运行建议

第一次一定按这个顺序：

1. 打开 GUI。
2. 保持 `dry-run` 打开。
3. 点击启动 UDP 监听。
4. 运行 MaixCAM 端代码。
5. 看 GUI 上目标点是否跟随皮卡丘移动。
6. 确认方向正确后，再连接 ESP32。
7. 关闭 `dry-run`。
8. 点击连接 ESP32。
9. 启用自动锁定。

`dry-run` 是保护开关。打开时，GUI 会计算命令并显示日志，但不会真的控制电机。

## 串口设置

默认：

```text
ESP32 串口：COM3
波特率：115200
```

如果连接失败，常见原因是：

- 端口选错。
- 串口监视器还开着，占用了 COM 口。
- `idf.py monitor` 没关。
- 其他串口工具没关。

Windows 同一个 COM 口同一时间只能被一个程序打开。

## 视觉状态怎么看

GUI 中的画布中心代表云台准星。

- 目标点在中心右侧：说明目标偏右。
- 目标点在中心左侧：说明目标偏左。
- 目标点离中心越远，误差越大。
- 目标点靠近中心，说明云台已经接近瞄准。

如果 GUI 显示方向和 MaixCAM 屏幕相反，优先检查：

- MaixCAM 端 `SEND_INVERT_X/Y`。
- GUI 端 X/Y 反向。

## 自动锁定做了什么

开启自动锁定后，GUI 会不断执行：

```text
接收 dx/dy
↓
平滑处理
↓
PID 计算
↓
限制最大步数
↓
发送 M x y 给 ESP32
```

例如：

```text
M 8 -3
```

表示让 X 轴走 8 步，Y 轴走 -3 步。

## 重要参数解释

### Kp

比例项。误差越大，动作越大。

- 太小：追得慢。
- 太大：容易冲过头、来回晃。

### Ki

积分项。用于消除长期小偏差。

本项目默认 `Ki = 0`，因为视觉追踪中积分项容易积累过量，导致目标靠近中心时还继续冲。

### Kd

微分项。看误差变化速度，用来提前刹车。

- 太小：不够稳。
- 太大：容易对噪声敏感。

### 死区像素

目标离中心很近时，不再控制电机。

作用：

- 防止在中心附近抖动。
- 让系统不要为了几像素误差一直来回修正。

如果你觉得“快到中心就不动了，但还没对准”，可以适当减小死区。

### 单次最大步数

每次最多给 ESP32 发多少步。

- 太小：追得慢。
- 太大：动作猛，容易过冲。

### 最小步进

PID 算出来的步数太小，转成整数后可能变成 0。最小步进可以让它在误差还存在时至少动一点。

### 误差平滑 alpha

用于减少视觉坐标跳动。

- 越大：反应越快，但更抖。
- 越小：更平滑，但更慢。

### ESP 脉冲半周期 us

GUI 连接 ESP32 后会发送：

```text
P 250
```

这个值越小，ESP32 输出 STEP 脉冲越快，电机速度越快。

不要一开始就设太小，先保守测试。
