# MaixHub 创建数据集与标注

这一页讲如何在 MaixHub 上创建数据集、上传图片、给目标画框。

## 打开 MaixHub

浏览器打开：

```text
https://maixhub.com/
```

注册并登录账号。

官方说明中提到，MaixHub 支持在线训练、在线标注、一键上传数据集，并且可以选择 MaixCAM 等平台进行训练。

## 选择任务类型

本项目是目标检测，所以创建数据集或训练任务时要选择：

```text
图像 / 目标检测
```

不要选成图像分类。

区别：

- 图像分类：只判断整张图是什么。
- 目标检测：要画框，识别目标位置。

本项目的 `皮卡丘识别.py` 用的是：

```python
detector = nn.YOLOv5(model=model_path)
```

所以训练时建议选择目标检测类模型，例如 YOLOv5s。

## 上传图片

把前面采集好的图片上传到 MaixHub 数据集。

建议上传前先检查：

- 文件能正常打开。
- 图片不要严重模糊。
- 不要有大量重复图片。
- 正样本和负样本都包含一些。

## 创建标签

标签名就是目标类别名。

例如识别皮卡丘，可以创建：

```text
pikachu
```

建议标签名用英文小写，不要用中文、空格和特殊符号。

好的标签名：

```text
pikachu
cup
car
red_block
```

不推荐：

```text
皮卡丘
my target
目标#1
```

## 如何标注

对每张含有目标的图片：

1. 选择对应标签。
2. 用矩形框框住目标。
3. 框尽量贴近目标外轮廓。
4. 不要框太大，也不要漏掉目标主体。
5. 保存标注。

标注框应该像这样理解：

```text
框住“目标本体”，不是框住整张图片，也不是框住目标周围一大圈背景。
```

## 多个目标怎么办

如果一张图里有多个同类目标，每个目标都要画一个框。

例如图里有两个皮卡丘，就画两个 `pikachu` 框。

如果只想训练识别一个目标类别，其他物体不要乱标。

## 负样本怎么处理

如果图片里没有目标：

- 不画框。
- 保持空标注。
- 训练参数里允许负样本时，保留这些图片。

负样本很有用，尤其当模型容易把其他东西误识别成目标时。

## 标注质量比图片数量更重要

100 张标得很准的图，通常比 500 张乱标的图更有用。

常见错误：

- 框偏了。
- 框太大。
- 漏标目标。
- 把不是目标的东西也标成目标。
- 同一个目标有时叫 `pikachu`，有时叫 `pkq`。

标签名必须统一。
