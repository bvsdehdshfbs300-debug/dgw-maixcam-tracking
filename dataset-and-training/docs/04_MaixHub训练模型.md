# MaixHub 训练模型

完成数据集和标注后，就可以创建训练任务。

## 推荐训练设置

新手可以按这个方向设置：

```text
数据类型：image
任务类型：detection / 目标检测
部署平台：maixcam
模型网络：yolov5s
输入尺寸：正方形尺寸优先，例如 224 x 224 或 320 x 320
训练轮数：100
学习率：0.001
批量大小：默认或 32
图像增强：可以打开镜像、旋转、模糊
允许负样本：如果上传了无目标图片，就打开
```

注意：如果选择 YOLOv5，有些训练配置要求输入尺寸是正方形。之前遇到过 `320 x 224` 不符合 YOLOv5 训练要求的情况，这时改成：

```text
224 x 224
```

或：

```text
320 x 320
```

## 图像增强是什么

图像增强就是训练时自动制造一些变化，让模型更不容易死记硬背。

常见增强：

- 镜像。
- 旋转。
- 模糊。
- 缩放。
- 亮度变化。

例如你只拍了正面图片，旋转增强可以让模型见到轻微倾斜的情况。

但增强不是万能的。真实拍摄的多角度数据仍然最重要。

## 训练时要看什么

训练过程中重点看：

- 是否成功开始训练。
- 是否报输入尺寸错误。
- 是否报数据集为空。
- 是否报没有标注。
- 验证集效果如何。
- 有没有大量漏检或误检。

MaixHub 的模型页面通常会显示数据集、训练参数和验证结果。官方模型库示例中也会列出平台、网络、输入尺寸、训练轮数、学习率等信息，这些可以作为你检查训练配置的参考。

## 训练完成后下载什么

训练完成后下载适合 MaixCAM 的模型文件。

通常需要两个文件：

```text
model_xxxxxx.mud
model_xxxxxx.cvimodel
```

本项目示例中是：

```text
model_280927.mud
model_280927.cvimodel
```

如果你训练出来的文件名不同，比如：

```text
model_123456.mud
model_123456.cvimodel
```

那么后面代码里的模型路径也要改。

## 如果训练效果不好怎么办

优先改数据集，而不是先改代码。

可以补充：

- 更多角度。
- 更多距离。
- 更多背景。
- 更多光照。
- 更多负样本。
- 更准确的标注框。

如果模型误识别其他东西，增加这些“容易误识别但不是目标”的负样本。

如果模型远距离识别差，补拍远距离目标。

如果模型侧面识别差，补拍侧面目标。
