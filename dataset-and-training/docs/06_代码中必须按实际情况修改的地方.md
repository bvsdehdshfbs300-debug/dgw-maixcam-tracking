# 代码中必须按实际情况修改的地方

这一页专门讲代码里哪些地方需要你根据自己的目标、路径和模型修改。

## `拍照.py`

### 数据集名字

当前代码：

```python
DATASET_NAME = "target"
```

这个名字会影响保存目录和图片文件名。

如果你拍皮卡丘，可以改成：

```python
DATASET_NAME = "pikachu"
```

如果你拍杯子，可以改成：

```python
DATASET_NAME = "cup"
```

建议使用英文小写，不要用中文和空格。

### 图片保存目录

当前代码：

```python
SAVE_DIR = f"/root/datasets/{DATASET_NAME}"
```

一般不用改。它会自动根据 `DATASET_NAME` 创建目录。

例如：

```python
DATASET_NAME = "pikachu"
```

对应保存目录就是：

```text
/root/datasets/pikachu
```

### 摄像头分辨率

当前代码：

```python
CAM_W = 640
CAM_H = 480
```

含义：

- `CAM_W`：采集图片宽度。
- `CAM_H`：采集图片高度。

新手建议先保持默认。分辨率越高，图片细节越多，但文件更大，上传和标注更慢。

## `皮卡丘识别.py`

### 模型路径

当前代码：

```python
model_path = "/root/models/model_280927.mud"
```

这一定要改成你实际复制到 MaixCAM Pro 的模型文件名。

例如你的模型叫：

```text
model_123456.mud
```

就改成：

```python
model_path = "/root/models/model_123456.mud"
```

### 模型类型

当前代码：

```python
detector = nn.YOLOv5(model=model_path)
```

如果你训练的是 YOLOv5，保持不变。

如果你用的是 YOLOv8：

```python
detector = nn.YOLOv8(model=model_path)
```

如果你用的是 YOLO11：

```python
detector = nn.YOLO11(model=model_path)
```

如果模型类型和代码接口不匹配，可能会加载失败或检测结果异常。

### 置信度阈值

当前代码：

```python
objs = detector.detect(img, conf_th=0.5, iou_th=0.45)
```

`conf_th` 是置信度阈值。

检测不到目标时可以降低：

```python
objs = detector.detect(img, conf_th=0.35, iou_th=0.45)
```

误识别太多时可以提高：

```python
objs = detector.detect(img, conf_th=0.65, iou_th=0.45)
```

### 标签显示

当前代码：

```python
msg = f"{detector.labels[obj.class_id]} {obj.score:.2f}"
```

它会显示模型标签和置信度。

标签来自你训练模型时设置的类别名。如果你在 MaixHub 里标签叫 `pikachu`，屏幕上就会显示 `pikachu`。

## 模型示例文件

```text
模型示例/model_280927.cvimodel

```

## 最容易忘记改的地方

新手最容易忘：

1. 训练了新模型，但 `model_path` 还是旧名字。
2. 训练的是 YOLOv8/YOLO11，但代码还写 `nn.YOLOv5`。
3. 标签名前后不统一。
4. 复制了 `.mud`，但忘了复制 `.cvimodel`。
5. `conf_th` 设置太高，导致看起来“识别不到”。
