# 先看懂整体流程

训练视觉识别模型并不神秘，可以理解成一句话：

你给 AI 看很多张图片，并告诉它“目标在哪里、叫什么”，它就会学会以后在新画面里把目标找出来。

## 本项目做的是哪种视觉任务

本项目做的是“目标检测”，不是简单分类。

### 图像分类

图像分类只回答：

```text
这张图里是什么？
```

例如：

```text
这张图是皮卡丘。
```

它不告诉你皮卡丘在图里的哪个位置。

### 目标检测

目标检测回答：

```text
图里有什么？
它在哪里？
可信度是多少？
```

例如：

```text
类别：pikachu
位置：x=80, y=120, w=160, h=200
置信度：0.91
```

所以目标检测需要你在训练前给图片画框，这一步叫“标注”。

## 一套完整流程

```text
采集图片
  ↓
筛选图片
  ↓
上传 MaixHub
  ↓
画框标注
  ↓
在线训练
  ↓
下载模型
  ↓
复制到 MaixCAM Pro
  ↓
运行识别代码
```

## MaixHub 起什么作用

MaixHub 是 Sipeed 提供的在线 AI 平台。它可以在浏览器里完成数据集上传、在线标注、模型训练和模型分享。

对新手来说，最大好处是：

- 不需要自己装 PyTorch。
- 不需要自己配置 CUDA。
- 不需要自己写训练脚本。
- 不需要懂复杂模型结构。
- 训练完成后能得到适合 MaixCAM 使用的模型文件。

你主要要做好两件事：

1. 拍好数据集。
2. 标注准确。

## 什么是模型文件

训练完成后，你会得到类似这样的文件：

```text
model_xxxxxx.mud
model_xxxxxx.cvimodel
```

在 MaixPy 代码里一般加载 `.mud` 文件：

```python
detector = nn.YOLOv5(model="/root/models/model_280927.mud")
```

但 `.mud` 通常会引用对应的 `.cvimodel`，所以两个文件都要一起复制到 MaixCAM Pro。

## 为什么训练效果不好通常不是代码问题

新手最容易误解的一点是：识别效果差，不一定是代码写错。

视觉模型效果主要取决于数据集：

- 你有没有拍到足够多角度。
- 你有没有拍远距离、近距离。
- 你有没有拍不同光照。
- 背景是否太单一。
- 标注框是否准确。
- 负样本是否足够。

模型不是“理解”目标，它是在学习你提供的图片规律。数据越接近真实使用场景，模型越容易在真实场景中识别成功。
