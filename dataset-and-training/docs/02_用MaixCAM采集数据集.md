# 用 MaixCAM 采集数据集

本项目提供了 `拍照.py`，它运行在 MaixCAM Pro 上，用来快速采集训练图片。

## 运行方法

1. 打开 MaixVision。
2. 连接 MaixCAM Pro。
3. 打开本文件夹里的 `拍照.py`。
4. 点击运行。
5. 屏幕显示摄像头画面后，点击 MaixCAM Pro 触摸屏拍照。

每点一次屏幕，会保存一张图片。

## 图片保存在哪里

默认保存目录：

```text
/root/datasets/target/
```

文件名示例：

```text
target_00000.jpg
target_00001.jpg
target_00002.jpg
```

## 代码中控制保存位置的部分

```python
DATASET_NAME = "target"
SAVE_DIR = f"/root/datasets/{DATASET_NAME}"
```

如果你要识别皮卡丘，可以改成：

```python
DATASET_NAME = "pikachu"
SAVE_DIR = f"/root/datasets/{DATASET_NAME}"
```

这样图片会保存到：

```text
/root/datasets/pikachu/
```

## 拍多少张合适

新手建议：

- 最低可尝试：50 张。
- 比较稳妥：100 到 300 张。
- 场景复杂：300 张以上。

如果目标只有一个，比如只识别一个皮卡丘玩偶，100 到 300 张通常已经能看到效果。

## 应该怎么拍

不要只在一个角度拍很多张。模型需要看到“同一个目标在不同情况下长什么样”。

建议覆盖这些情况：

- 正面。
- 左侧。
- 右侧。
- 俯视。
- 仰视。
- 近距离。
- 远距离。
- 目标在画面中心。
- 目标在画面边缘。
- 明亮环境。
- 偏暗环境。
- 不同背景。
- 手拿着目标。
- 目标放在桌面上。

## 不要这样拍

这些数据对训练帮助不大：

- 连续拍几十张几乎一模一样的图片。
- 图片严重模糊。
- 目标被遮挡太多。
- 目标太小，小到人眼都不容易看清。
- 只有一种背景。
- 只有一种光照。

## 负样本怎么拍

负样本就是“不包含目标”的图片。

例如你训练识别皮卡丘，负样本可以是：

- 空桌面。
- 其他玩偶。
- 杯子。
- 电脑键盘。
- 云台结构。
- 和真实使用场景相似但没有皮卡丘的画面。

负样本的作用是告诉模型：

```text
这些东西不是皮卡丘，不要乱框。
```

## 负样本要不要标注

目标检测任务中，负样本一般不画框。

也就是说：

- 有目标的图片：给目标画框。
- 没目标的图片：不画框，保持空标注。

如果 MaixHub 训练参数里有“允许负样本”或类似选项，使用负样本时要打开。

## 拍完后怎么导出到电脑

常见方法：

- 用 MaixVision 的文件管理功能下载 `/root/datasets/target/`。
- 或用 MaixCAM 提供的文件传输方式导出。
- 或连接网络后通过远程文件管理工具复制。

导出后建议在电脑上整理成一个文件夹，比如：

```text
my_dataset_images
├─ target_00000.jpg
├─ target_00001.jpg
└─ target_00002.jpg
```

上传 MaixHub 前，先把明显模糊、重复、错误的图片删掉。
